## 2. The seven limitations in "What went wrong"

| # | Limitation | Status |
|---|---|---|
| 1 | Number rule accepted a number for the wrong reason | **Fixed**: numbers are checked against their context; regression tests ("After 2 steps" on a 1-step witness is rejected) |
| 2 | Names validated only in backticks | **Fixed for the common cases**: bare names after thread/mutex/lock/variable are checked. Free prose that mentions an invented single-letter name elsewhere can still slip through |
| 3 | One label masks another | **Fixed**: `detail["findings"]` lists every kind found, ordered by severity, on the default path |
| 4 | Lockset-style race detection, values not tracked | **Still true.** (State-based: a race is reported only when two conflicting accesses are simultaneously next, so semaphore-protected sections are not false positives) |
| 5 | Placeholder bounds | **Partly fixed**: `loop_unroll` comes from the parser; `buffer` is still 0 |
| 6 | Awkward grammar | **Fixed in the general narrator** ("letting `T2` lock `b` leaves the safe region, whereas letting `T1` lock `b` keeps a safe completion reachable"). The original slice narrator is kept unchanged as an oracle |
| 7 | Trivial one-step race witness | **Still true** (correct but not instructive; a lost-update witness is not built) |

## 3. Measured results **[script]**

- Tests: run `pytest -q` (the suite is offline); CI also reports coverage (floor 90%).
- Classifier (`eval/results/classifier.md`): 39 programs (44 program/fairness cases): Tier A
  agreement, replay of every witness, Tier B versus Tier A on symmetric cases, Tier C
  detection per bug kind over 20 seeds. **These are agreement with labels derived by
  reasoning, not accuracy.** Verify every label in `eval/dataset.py` by hand (or double-annotate
  and report disagreements, as the plan requires) before quoting precision or recall.
- Efficiency (`efficiency.md`): states/second, bytes/state, the interleavings-versus-states
  table (121 states vs 184,756 interleavings at n=10), Tier B reduction per program. Note
  honestly that at n of 1 or 2 the state count *exceeds* the interleaving count, and that Tier B
  does not always reduce wall-clock time (canonicalisation has a cost).
- Faithfulness (`faithfulness.md`): checker rejection of the four tamper kinds, template
  acceptance, **and** the demonstrated blind spot (a false cause with correct facts is accepted).
  No real-LLM pass or regeneration rate exists until recorded answers do.
- Diagnosis (`diagnosis.md`): **synthetic and circular**; plumbing checks only.
- Router (`router.md`): 31 of 32 on messages written by us, rules not tuned to them; the
  misroute is a yes/no conceptual question ("Is the C-SCAN algorithm fairer than SCAN?") sent
  to the simulator. Real traffic is unmeasured.
- RAG (`rag.md`): six-section sample corpus, lexical embedder. Two top-1 misses and one
  off-topic leak (a poem request matched on the word "write"); both are lexical effects a
  semantic embedder should reduce, which is exactly what the real evaluation must test.

## 4. New limitations discovered while building (add these to the report)

- The evaluation labels were written by one author (an AI assistant) by reasoning, not by two
  independent annotators.
- PCT stops at the first failure it finds, so for programs with several failure kinds a sampled
  run may report a different (replay-verified) kind than the most severe.
- Tier B is symmetry reduction only. Sleep sets and DPOR (named in the plan) are not built;
  the symmetric families (rotated dining philosophers, identical threads) benefit, other
  programs do not.
- Condition variables are modelled with FIFO wake-up and no predicate (no shared values), so
  "wait without re-checking a condition" is always a lost-signal risk; the reader-writer
  problem with counters cannot be expressed.
- Starvation needs `forever` loops and a stated fairness assumption (weak or strong), and is
  analysed on exhaustive (Tier A) graphs only.
- Banker's safe sequences are not unique; diagnosis accepts any valid one. For disk scheduling a
  head path that omits the disk edge is word-for-word the correct service order of SCAN, so the
  engine reports "correct as an order, but possibly the LOOK mistake" instead of guessing.
- Round Robin and similar results depend on a stated tie-break convention (new arrival first).
- Not measured anywhere: learning outcomes, real-LLM latency or token cost at scale, accuracy
  on real student answers (no data collected; approval status is yours to state).
